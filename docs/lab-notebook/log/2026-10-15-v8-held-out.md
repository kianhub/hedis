# 2026-10-15 — v8 held-out evaluation (React Native 0.85, scored once)

**Pre-registration:** `c3b90d8`. **Freeze:** `cffd75f` on `research/v8-freeze`; `split.v8.json` sha256 `b81c8e1e…3946`. Off-box copy: release `v8-freeze-cffd75f` (sha256 `6f379a9a…fb859`). **Result:** `a2aab03`, `research/v8/RESULT.md`. Scored by Hedis Researcher at ~21:05 CT. v8 is now burned.

**Hypothesis.** M39 improves exact package+version F1 over the thesis baseline (t35) on held-out React Native 0.85 applications, and the unsupported flag rate falls toward zero.

**Data.** 10 applications. rn085 (7): marlin 1.3.0, imagetopdf 1.1, dothething 1.2.1, minmobile 1.0.62, wixrnn 8.8.7, readtrace 1.0.6, ysclaude 1.0.9. Control (3): appcues 1.0.12 (0.74.5), solana 3.0.0 (0.76.9), gorhom 5.1.4 (0.76.0). blink-beta, breathly and zeus excluded (development).

**Configuration.** `bin/hedis-m39` (sha256 `8b475e7c…2ee297`) at cutoff `6ad180000000000000000000`, M38 flags plus `--unsupported-cov 0.40`; metric `oneclass.py --subsha`. Baseline t35 (`hedis-vset` + `thesis_vset.py`) at the same cutoff.

Controls, per application only (n = 3 is too small for a group figure): appcues 0.727 / 0.061, gorhom 0.625 / 0.167, solana 0.889 / 0.121 (M39 / t35). Unsupported flags, M39 on rn085: 0/7.

Arithmetic of all F1 values was checked against the counts.

**Interpretation.** On bytecode 98, t35 produces no output; the rn085 comparison therefore measures coverage, not matching accuracy, and must be stated as such. Held-out F1 (0.373) is far below in-sample F1 on the 0.85 development applications (0.885): a genuine generalisation gap. Most false negatives are the correct package at the wrong version (safe-area-context, screens, reanimated), plus three gesture-handler misses; three false negatives fall on packages with failed subpath builds (svg ×2, flash-list), all wrong-version. Hypothesis, not yet verified: version selection, not package detection, is now the dominant error.

**Threats to validity.** (1) t35 baseline is a crash, not a scored competitor, on rn085. (2) Small n (7 + 3). (3) `t35_v8.sh` inherited the `thesis_vset` stdout→`.tv.log` quirk; control predictions were copied as produced, matcher not re-run. (4) 72 failed fingerprint builds reduce coverage.
